Cam740

'Cam740' poate fi utilizat pentru diagnoza sistemelor Sinumerik 840D, Sinamics sau Step7 conectabile prin Ethernet, Profibus, MPI.

Nu este necesara instalarea programului, acesta este portabil iar toate datele si setarile sunt salvate in fisiere .INI in directorul propriu.

'Cam740' utilizeaza Qt si Snap7 sub Licenta LGPL3 pentru a stabili comunicatia cu echipamentul Sinumerik/Sinamics/Step7.
Proiectul poate utiliza si interfata Prodave daca fisierul DLL este copiat in directorul de lucru si licenta acestuia este activata.

Virtual MCP

'Virtual MCP' este un mic emulator pentru panourile de control masina MCP din sistemele SINUMERIK.
Poate fi folosit pentru controlul de la distanta ("remote") a unui echipament SINUMERIK real, in scop de scolarizare, de exemplu.

Nu este necesara instalarea programului, acesta este portabil iar toate datele si setarile sunt salvate in fisiere .INI in directorul propriu.

sparesNet

'sparesNet' este o aplicatie portabila, scrisa in node.js, pentru verificarea disponibilitatii pieselor de schimb Siemens utilizand informatiile despre produs din paginile web IndustryMall.

Versiunea actuala, bazata pe electron si puppeteer-in-electron, este in faza de test.

Cam410

'Cam410' este o serie de mici simulatoare pentru cursurile de scolarizare Step7/TIA. Simulator al benzii transportoare din standurile de scolarizare Step7/TIA, a liniei de productie pentru cursurile Safety Integrated, etc.

Create MyHMI /3GL...

Create MyHMI /3GL

'Create MyHMI /3GL' poate fi utilizat pentru a crea extensii HMI pentru SINUMERIK 840D sl si SINUMERIK ONE sau interfete utilizator de sine statatoare pentru SINUMERIK 840D sl, SINUMERIK ONE sau SINUMERIK MC.
SINUMERIK Create MyHMI /3GL permite dezvoltarea de aplicatii in limbaje de nivel inalt utilizand C++ impreuna cu clasele speciale dezvoltate in Qt pentru SINUMERIK Operate pe SINUMERIK PCU 50.5, SIMATIC IPC427E sau IPC477E, precum si pe SINUMERIK NCU 7x0.
